# Routing — which platforms suit which post

Every platform gets a card. This table only sets the card's stance, and tells
the grader how hard to push back.

| Platform | tool post | essay | Why |
|---|---|---|---|
| LinkedIn | recommended | recommended | Both land; the audience is mixed and forgiving |
| X | recommended | recommended | Tool posts do better, essays still travel |
| Bluesky | recommended | recommended | Dev-heavy, low volume, cheap to include |
| Reddit | recommended | recommended | **Different subs entirely** — see below |
| Hacker News | recommended | **discouraged** | HN buries personal-growth writing. Flag it, don't quietly submit it |
| Dev.to | recommended | recommended | Canonical cross-post; costs nothing, compounds SEO |

## Subreddit selection

Reddit is the one platform where the *destination* is a real decision. The
drafter must name specific subs and justify each in one line — "this sub
allows self-posts about X and the top posts this month include Y".

- **tool** — subs matching the technology, not r/programming by default.
  r/programming is strict about self-promo and mostly rejects it.
- **essay** — the subs about the *subject* (habits, learning, discipline,
  writing), never developer subs.

Two hard rules that override any draft quality :

1. **Never suggest a sub the author has no history in.** Posting a link as a
   first action in a community is the definition of spam, and the sub's
   automod usually agrees.
2. **Reddit is manual, always.** The card is a draft plus a destination, not
   an action.

## Hacker News

Title only. If the post is a tool the author built, `Show HN: ` prefix and
the submission should point at the tool, not the blog post about the tool.

For an essay, the honest answer is usually **REJECT** with one line saying
why. Occasionally an essay with a genuine technical or contrarian argument
belongs — but the bar is the front page, not "it might do okay".

## Timing (advisory, printed on the page)

Do not schedule anything. Just note on each card when that platform's
audience is awake, so the human can decide :

- LinkedIn — weekday mornings, author's local business hours
- X / Bluesky — weekday mornings or early evenings
- Reddit — depends entirely on the sub's timezone skew
- Hacker News — weekday mornings US Eastern
- Dev.to — any time; it's evergreen and search-driven

## Drip, don't blast

Print this line on the page: posting all six the same hour wastes five of
them. A sane default spread is LinkedIn / X / Bluesky on day 0, Dev.to on day
1, Reddit on day 3, Hacker News on day 7 if it qualifies.
