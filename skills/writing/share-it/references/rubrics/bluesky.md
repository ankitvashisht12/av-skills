# Rubric — Bluesky

300 characters. Almost always a single post.

## Format

Closest to early Twitter : conversational, low-polish, no hashtag culture,
and the link preview card does real work — so the post does **not** need to
describe what the link is. It needs to give a reason to care.

Because the preview already shows the title and description, repeating either
of them is wasted characters. Say the thing the preview can't.

## Blockers

- [ ] ≤ 300 characters including the URL
- [ ] Does not restate the post's title or meta description
- [ ] No hashtags
- [ ] Not a verbatim copy of the X draft — same idea is fine, same sentences
      are not
- [ ] Hook does not repeat the opening move of the last 3 Bluesky hooks
- [ ] Nothing from voice.md's banned list

## Nits

- Lowercase, unpunctuated openings suit the platform
- One personal, slightly unguarded line outperforms one polished line
- Threading is possible but rarely worth it here

## Score

- **9–10** — sounds like a person thinking out loud, and you'd still click
- **7–8** — good, slightly too composed
- **5–6** — a shortened LinkedIn post
- **≤4** — a blocker, or it's just the title plus a URL
