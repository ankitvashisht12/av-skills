# Rubric — X (Twitter)

280 characters per post. Decide single vs thread before writing.

## Single or thread

**Single is the default, for tools as well as essays.** One idea, the link
does the rest. Higher completion, no thread tax.

A **thread** needs 3+ beats that are *separately interesting to a stranger* —
not three facts the author finds interesting about one thing. Build detail
(how it was made, how it was verified, what didn't regress) is one beat at
most, usually zero. If the beats only make sense in sequence, it's one post
with the middle cut out. 3–4 posts, never more.

State which you chose and why in one line above the draft. If you chose
thread, name the stranger who cares about post 3 — if you can't, write a
single.

## Structure

Post 1 must survive alone in a timeline with the rest collapsed. It is not an
introduction to the thread; it is the thread's best line.

The link goes in the **final** post. If it's a thread, the last post is the
link plus a one-line reason to click — never a bare URL.

## Blockers

- [ ] Every post ≤ 280 characters, counted, including the URL
- [ ] Post 1 works with nothing after it
- [ ] Link is in the last post only
- [ ] No "a thread 🧵", no numbered "1/7" scaffolding
- [ ] No hashtags (they read as 2016 on this platform)
- [ ] Hook does not repeat the opening move of the last 3 X hooks
- [ ] Nothing from voice.md's banned list
- [ ] Thread has no filler post — every post earns its place
- [ ] Thread was justified against the bar above, not chosen by default
- [ ] Every post parses on one read; no clause only a specialist finishes

## Nits

- Lowercase openings are fine here and often read better
- One concrete detail (a number, a name, a specific) beats one adjective
- Line breaks inside a post are cheap and help
- If a thread's post 4 is weak, cut to three posts

## Score

- **9–10** — post 1 would be quoted on its own
- **7–8** — clear and native, but the hook is a statement not a hook
- **5–6** — reads like a headline with a link stapled to it
- **≤4** — a blocker, or it's the blog title rephrased
